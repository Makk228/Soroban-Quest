## Что получилось

**Soroban Quest** — тренажёр ментальной арифметики в игровой форме. Сервер на Kotlin, модульный монолит.

**Модули** (границы проверяет компилятор: публичен только пакет `api`, всё остальное `internal`):

| Модуль | Содержание |
|---|---|
| `shared` | идентификаторы, ошибки с кодами, порты `TransactionRunner` / `DomainEventPublisher` |
| `identity` | регистрация, вход, JWT + ротация refresh-токенов с обнаружением кражи, BCrypt |
| `training` | 5 режимов, детерминированная генерация заданий из `seed`, агрегат сессии, очки (скорость × комбо) |
| `progression` | опыт, уровни, серии дней, дневная цель, 11 достижений, статистика по режимам |
| `leaderboard` | недельный (ISO) и общий рейтинг с местами через `rank()` |
| `api/rest` | контроллеры, валидация, RFC 7807, JWT-фильтр, Swagger |
| `bootstrap` | Spring Boot, шина событий, транзакции, Docker |

**Ключевые решения под требования лабы:** домен без Spring/SQL/HTTP (порты + адаптеры); межмодульная связь только через события в одной транзакции; схема БД на каждый модуль + Flyway-миграции внутри модулей; конкурентность через `SELECT FOR UPDATE`, версии строк и `ON CONFLICT`; идемпотентные ответы на задания; секреты только из окружения (приложение не стартует без `SOROBAN_JWT_SECRET` ≥ 32 байт).
